# inkling v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Offline reading + speaking app with 30 lessons, e-reader themes, timer, progress, 30-day challenge and voice recording.

**Architecture:** Lessons are JSON assets parsed into models; progress lives in a KeyValueStore (shared_preferences) behind pure functions with an injectable clock; UI with Riverpod.

**Tech Stack:** Flutter 3.47.7, flutter_riverpod, shared_preferences, record, just_audio, path_provider, Literata font.

**Spec:** `docs/specs/2026-10-21-inkling-design.md`

## Global Constraints

- No network permission needed; nothing leaves the phone.
- UI copy in Spanish; lessons in English; code in English.
- Tense ids: presentSimple, presentContinuous, pastSimple, pastContinuous, presentPerfect, futureWill, futureGoingTo.
- Lesson length 280–420 words.

## Review Focus

- A `[[mark]]` that differs in case from its phrase ("Look into" vs "look into") must still resolve (test in Task 1).
- All lessons read → today's lesson is the least recently read, never null (Task 2).
- Streak when last read was yesterday stays alive; two days ago breaks it (Task 2).
- Timer must not count time while the app is in background (Task 4, manual).
- Microphone permission denied → clear message, no crash (Task 5).
